FORMULA:
  baseMEV = scaledMEV(muscle, experience)
  priorityBonus = (tier == priority) ? 4 : 0
  base = Int((baseMEV + priorityBonus) × blockMultiplier)
  Then clamped: max(MV, min(base, effectiveMRV))

Block multipliers: accum=1.0, intens=0.65, reaccum=1.15, peak=0.50

MV (maintenance volume floor):
  Chest=6, Back=6, Quads=6, Calves=6
  Hamstrings=4, Glutes=4, Delts=4, Triceps=4, Biceps=4

╔══════════════════════════════════════════════════════════════════════════════╗
║  TABLE 12 — PROGRESSION ENGINE DECISIONS                                   ║
║  What happens after each workout?                                          ║
╚══════════════════════════════════════════════════════════════════════════════╝

───── WEIGHT PROGRESSION RULES ─────────────────────────────────────────────────

  Condition (all working sets)        Rule        Weight change
  ──────────────────────────────────  ──────────  ─────────────────────────
  All sets ≥ targetRepsHigh           .progress   +increment
  Not all at top, not 2+ misses      .hold       same weight
  2+ sets < targetRepsLow, 2 in row  .backoff    ×backoff% (T1=94%, T2=90%, T3=85%)

───── INCREMENTS ───────────────────────────────────────────────────────────────

  Tier   Imperial                           Metric
  ─────  ─────────────────────────────────  ──────────
  T1     ≥185lb → +10lb, <185lb → +5lb     +2.5kg
  T2     +5lb                               +2.5kg
  T3     +2.5lb                             +1.25kg

───── MODIFIERS (applied in order) ─────────────────────────────────────────────

  1. IFI modifier:
     IFI < 0.10 (fresh)       → no change
     IFI 0.10-0.24 (optimal)  → no change
     IFI 0.25-0.39 (fatigued) → if progressing, override to hold
     IFI ≥ 0.40 (overreach)   → force backoff

  2. RPE brake (if RPE logged):
     RPE ≥ 9.5 + progressing  → block, hold at current weight
     RPE ≤ 7.0 + holding      → bump, add one increment
     RPE 7.1-9.4              → no change

  3. Progression rate:
     .fast + T1 + progress    → add 50% more increment
     .slow + T1 + progress    → require 2 consecutive successes first
     .normal                  → no change

───── BACKOFF WEIGHT (T1 only) ─────────────────────────────────────────────────
  backoffWeight = recommendedWeight × 0.92, rounded to plate

  Example: recommend=235lb → 235×0.92=216.2 → 215lb
  Example: recommend=100kg → 100×0.92=92 → 92.5kg

  T2/T3: backoffWeight = recommendedWeight (no separate backoff)


╔══════════════════════════════════════════════════════════════════════════════╗
║  TABLE 13 — VOLUME DECISION ENGINE                                         ║
║  After each workout, should next week have more/fewer/same sets?           ║
╚══════════════════════════════════════════════════════════════════════════════╝

  Priority  Condition                                    Decision
  ────────  ───────────────────────────────────────────  ──────────────────
  1         IFI ≥ 0.40 (acute overreach)                 DELOAD
  2         Fatigue stall diagnosed                       DELOAD
  3         Weight is progressing (or e1RM rising)        HOLD VOLUME
  4         User responds to intensity not volume         HOLD VOLUME
  5         Weight was just backed off                    HOLD VOLUME
  6         Intensity stall (not pushing hard enough)     HOLD VOLUME
  7         IFI 0.25-0.39 OR volume stall                REDUCE (1-2 sets)
  8         Stimulus evaluation says insufficient         ADD (1-2 sets)
  9         None of the above                            HOLD VOLUME

  ADD sets requires: (stimScore > 0.5) AND (confidence ≥ 0.5)
  Minimum 2 of these 3 signals must fire:
    • e1RM flat (not declining, not rising)
    • IFI fresh (< 0.10)
    • Stalled at same load for ≥ requiredWeeks (2-3 depending on phase)

  Sets added: 2 if IFI fresh, 1 if IFI optimal (capped at MRV)
  Sets removed: min(2, currentSets - MEV) — never below MEV
